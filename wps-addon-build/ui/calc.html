使用说明
变量约定：所有表达式中用 x 代表当前单元格的值。

① 目标单元格：打开弹窗时会自动填入当前选区与已用区域的交集。
    支持手改（$A$1:$B$11 / A1:B11 / 命名区域）。
    点右侧「选择…」按钮可用鼠标重新框选。
② if 条件：返回 true/false。留空 = 无条件全部进入 then。
③ then：当 if 为 true（或 if 留空）时执行。留空 = 不做任何操作。
④ else：当 if 为 false 时执行。留空 = 不做任何操作。
    ▸ then/else 支持两种写法：
      a) x = <表达式>（明确赋值，直观）
      b) 只写 <表达式>（返回值即新的 x）
    ▸ 可直接用 sqrt(x)、abs(x)、PI 等 Math 函数，无需 Math. 前缀，不区分大小写
    ▸ 可直接用 x.trim()、x.length、x.toLowerCase() 等 String 方法，检测到时自动按字符串处理

示例：把 $A$1:$B$11 中小于 0 的值变成 0，其他取反。
  目标单元格：$A$1:$B$11
  if   : x < 0
  then : x = 0
  else : x = -x
